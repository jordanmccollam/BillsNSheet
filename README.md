# BillsNSheet
A Budget Planner Application

## Technologies / Packages Used
- React.js
- Hygen.io
- Bootstrap
- React-Bootstrap
- Prop-Types
- Classnames
- SASS
- Moment.js


## GETTING STARTED

STEP 1 - run 'npm i' to install all packages. It should install packages for client folder as well. Don't worry about it.

STEP 2 - Add a .env file with the following variables:
    - MONGO_CONNECTION_STRING
    - REACT_APP_ENV
    - REACT_APP_AUTH0_DOMAIN
    - REACT_APP_AUTH0_CLIENT_ID

    You should be able to get these things from Mongo DB's Atlas, and Auth0

STEP 3 - Copy and paste this .env file into the client folder
STEP 4 - run 'npm run start' to boot the server
STEP 5 - run 'npm run start-client' to run the client side
